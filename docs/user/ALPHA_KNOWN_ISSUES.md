# 已知限制

- 基本Alpha子集已通过独立复核：19dc第一项目与1eb独立第二项目分别保留实际源码依据；1eb完成指定复核、accepted后继和普通重启。完整85任务路线未齐，不能将子集验收解释为所有规划功能完成。历史429、额度失败和unknown记录保留，当前成功不保证账号额度或未来请求可用。
- 已测试版本及 textInput/resume/historyRead/roleTools 覆盖见支持摘要，仅供参考。其他版本允许尝试运行，实际接口不支持时如实报告；未测试不冒称已通过。
- 受管Codex默认只读。当前首版由ZCode写文件，Codex独立只读核对并保存持久summary/裁决。任意Codex执行写入不在已验证范围。
- 任意现有日常聊天自动接纳、原生UI项目分组、任意严格模型/推理切换不是首版承诺。工作目录分组不能冒称Harness原生“项目”。
- 原生轮执行期限到限会保留unknown，不自动当未发送或重试。idle、无工具、进程退出都不等于原轮业务终态。缺证据时可能需要人工等待维护者处理。
- 对话页手动刷新、普通分页，不显示工具参数/内部推理/完整媒体；快照有期限和大小限制。界面可能存在刷新延迟和轻微样式问题。
- 模型偏好有Requested/Resolved/Effective区分；保存不是实际生效。默认已验证模型优先，配置未知或严格请求不支持时停发。
- Windows开发机验证不等于干净Windows验收；8小时稳定性、真人效率基线、多平台及完整高级组织管理未作为首版已通过功能。
- 项目金额上限无法强制保证，正常模型调用使用现有账号额度。不使用reset credit，不扩大权限/预算或解除用户暂停。
- 本候选采用Apache-2.0，维护者hhhzingy，目标https://github.com/hhhzingy/ProjectOrch；用户已授权完成Alpha后发布。本包构建时尚未公开；私密漏洞报告入口尚未实际启用，不提供虚构邮箱。
