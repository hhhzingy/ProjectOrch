# 测试范围

`unit/` 当前验证运行时版本边界。执行包的 Schema 正反例及防伪证据回归仍在 `scripts/pack-tools.test.mjs`，不视为应用功能测试。

集成测试（Integration）、适配器合同测试（Contract）、端到端测试（E2E）、原生测试（Native）由相应任务建立。当前不添加空测试或始终成功的脚本；原生测试只面向专用项目与已明确选定会话。

T011 新增 `storage/` 与 `test:integration`，使用真实独立磁盘 SQLite 库验证迁移、约束、竞争和强制终止后的原子恢复（13 项）。使用锁定 Node 24.22.0，临时库和备份会在测试后清理；不将该套件扩大解释为尚未实现的网关/业务集成测试。
